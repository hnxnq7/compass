## CMU NeuLab (Graham Neubig)

*Graham Neubig's lab at CMU's Language Technologies Institute — built WebArena, the self-hosted realistic-website benchmark most browser-agent work is still evaluated against.*

## What they do
- NLP/agents lab focused on language technologies that act in real environments, with web agents as a major thread since 2023
- Builds fully-functional, self-hosted clones of real site categories (e-commerce, forums, GitLab, CMS, maps) specifically so agents can be evaluated on live interaction, not static snapshots

## Where they fit
- WebArena is the field's answer to "how do you get realism and reproducibility at the same time" — the core tension this note calls out under "why hasn't it been solved"
- VisualWebArena extends the same approach to multimodal, visually-grounded web tasks, tracking the field's shift toward screenshot-native agents

## Notable work / recent moves
- **WebArena: A Realistic Web Environment for Building Autonomous Agents** (Zhou, Xu, Zhu, Zhou, Lo, Sridhar, Cheng, Ou, Bisk, Fried, Alon, Neubig; ICLR 2024) — 812 long-horizon tasks across five self-hosted, fully-functional site categories
- **VisualWebArena** (Koh et al., NeuLab; 2024) — multimodal extension evaluating visually-grounded web agents
