## Princeton NLP (Karthik Narasimhan's group)

*Karthik Narasimhan's lab at Princeton — co-creators of ReAct, SWE-bench, and SWE-agent, three of the most-cited reference points in language-agent research.*

## What they do
- Academic NLP/agents lab building language agents that interact with real, complex environments (code repositories, web, games) rather than single-turn QA
- Trains and evaluates agents on tasks with genuine multi-step structure, with an emphasis on open benchmarks the rest of the field then adopts wholesale

## Where they fit
- SWE-bench and SWE-agent are the de facto standard for evaluating and building coding agents — most industry coding-agent leaderboards report against SWE-bench Verified
- ReAct is the foundational reasoning-plus-acting paradigm nearly every subsequent long-horizon agent architecture builds on or cites

## Notable work / recent moves
- **SWE-bench: Can Language Models Resolve Real-World GitHub Issues?** (Jimenez, Yang, Wettig, Yao, Pei, Press, Narasimhan; ICLR 2024, oral) — real GitHub issue/PR pairs across 12 Python repos; became the standard coding-agent benchmark
- **SWE-agent** (Yang, Jimenez, Wettig, Lieret, Yao, Narasimhan, Press; NeurIPS 2024) — the agent-computer interface design that made SWE-bench solvable at scale
- **ReAct: Synergizing Reasoning and Acting in Language Models** (Yao, Zhao, Yu, Du, Shafran, Narasimhan, Cao; ICLR 2023) — the reasoning-then-acting loop most agent scaffolds still use
