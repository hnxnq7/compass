## OpenClaw

*Viral open-source, self-hosted personal AI agent — connects a model to your local files and messaging apps and lets it act autonomously, not just chat.*

## What they do
- Self-hosted agent that connects to Claude, GPT-4, Gemini, or DeepSeek (bring-your-own API key) and executes real actions: shell commands, file management, web automation, messaging (WhatsApp, Discord)
- Extensible via 100+ preconfigured "AgentSkills"
- Memory stored as plain markdown files on disk — everything runs locally, nothing server-side

## Where they fit
- A real-world stress test of [[Computer-Use & Browser Agents]] and [[Long-Horizon Planning & Memory]] outside a lab context — it's an ordinary person's machine running an always-on agent with real filesystem and messaging permissions, which is exactly the trust/permissions tension those fields flag as unresolved

## Notable work / recent moves
- Created by Peter Steinberger in late 2025 as "Clawdbot," renamed to "Moltbot" then "OpenClaw" (Jan 2026) after trademark concerns
- Surpassed 100,000 GitHub stars by February 2026
