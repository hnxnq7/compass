## OpenCode

*Open-source, terminal-first AI coding agent — the model-agnostic, self-hostable counterpart to closed coding agents like Devin or Claude Code.*

## What they do
- Terminal/IDE/desktop coding agent that plans, edits files, runs terminal commands, and debugs itself
- Model-agnostic: supports 75+ providers (OpenAI, Anthropic, Gemini, AWS Bedrock, Groq, Azure, OpenRouter, etc.) rather than being tied to one lab
- Local-first and privacy-oriented — doesn't store code or context data server-side

## Where they fit
- The clearest open-source, provider-agnostic entry in [[Coding Agents & AI Software Engineering]] — worth tracking as a counterweight to the vertically-integrated coding agents (Devin, Claude Code) since it represents the "bring your own model" end of the spectrum
- Relevant to [[Spec-Driven Coding & Development]] as one of the growing set of agent platforms adopting structured spec-driven workflows rather than ad-hoc prompting

## Notable work / recent moves
- Over 160,000 GitHub stars, ~900 contributors, used by 7.5M+ developers monthly as of mid-2026
